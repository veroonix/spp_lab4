# СПП Лабораторная работа №4 — Многопользовательская веб-игра

Многопользовательская веб-игра в режиме реального времени на WebSockets.

## Ссылка на игру

**https://spplab4-production.up.railway.app/**


## Что это за игра

Минималистичная multiplayer-песочница:

- Каждый игрок — **цветной квадрат** на поле 600×400 со своим именем
- Перед игрой можно **ввести имя** и **выбрать цвет** из палитры (настройки запоминаются в браузере)
- Управление — **стрелки** (или WASD)
- По полю разбросаны **монетки четырёх видов** — за цвет монеты дают разное количество очков:

  | Монета | Цвет | Очки | Частота |
  |---|---|---|---|
  | Бронзовая | `#cd7f32` | 1 | частая |
  | Серебряная | `#c9d1d9` | 2 | обычная |
  | Золотая | `#ffd700` | 3 | редкая |
  | Рубиновая | `#e0115f` | 5 | очень редкая |

- Все действия **синхронизируются мгновенно** через WebSocket
- Игроки **не проходят сквозь друг друга** (коллизия)
- **Оффлайн-игроки не блокируют движение**, а если на тебя «сели» или ты вернулся в занятую клетку — при попытке хода сервер автоматически отодвигает на ближайшее свободное место
- При потере связи — **автоматическое переподключение** с сохранением имени, цвета, очков и позиции

Виды и ценность монет настраиваются в `config.json` (секция `COIN_TYPES`: цвет, очки и вес выпадения).

## Стек

- **Backend:** Node.js + [ws](https://github.com/websockets/ws) — WebSocket-сервер и раздача статики
- **Frontend:** чистый JavaScript + HTML5 Canvas (без фреймворков)
- **Хранилище:** `state.json` (сохраняется на постоянный volume)
- **Хостинг:** [Railway](https://railway.app) — Web Service + Dockerfile + Volume
